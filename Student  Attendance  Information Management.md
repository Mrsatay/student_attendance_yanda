College Computer Major Computer Science & Technology Class 2351520115 Student ID Student Name Project Title Student Attendance Information Management Start Date September 7, 2026 Completion Date December 31, 2026 Place Shenyang Aerospace University Design Tasks and Requirements： Design Tasks: Write a student attendance information management program for teacher. The information includes student ID, name, class, course, date, status (absent/late/punctual). The program has the following capabilities:

1. Login the system with username and password.
2. Add a new attendance information;
3. Delete someone's information;
4. Modify someone's information;
5. Display all the attendance information;
6. Search a specified student‘s information using student’s name or ID as the keyword;
7. Sort the attendance information by date in chronological order ;
8. Count the number of students by class;
9. Import attendance information from a text file;
10. Export all the attendance information into a text file. Design Requirements:
1. Implement the project with Object Oriented Programming;
2. Design a friendly GUI for information management;
3. Check the data validity when entering information;
4. The main interface should have a main menu;
5. Write the project report in accordance with the specification of course design report.
